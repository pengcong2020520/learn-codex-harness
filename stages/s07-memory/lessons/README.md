## s07-memory · 记忆开关由服务端掌握

提炼交给 Codex，开关、位置和可见范围留在服务端；客户端只能查看和提出设置。

观察：记忆默认关闭，配置非法时拒绝启动；启动时读回 Codex 实际配置，不一致就报错，不假报开启；只读三个固定文件，拒绝符号链接和硬链接；会话参与设置先查总开关、项目归属和活动 turn，只调用 thread/memoryMode/set。

边界：离线临时目录与真实记忆模块；RPC 为 fixture，不启动真实 Codex 或外部模型。配置只使用测试输入，真实项目 .env 不会被读取。
