# s02 · 可执行机制实验

在本阶段目录使用 Node.js 24+；已安装依赖后运行：

```sh
npm run lesson -- list
npm run lesson -- s02-fifo
```

每课先输出学习问题、真实校验命令、预期观察、原因和证据边界，再运行本目录的模块测试。预期观察不是成功宣告；以 Node 测试报告的 pass / fail / skip 为准。参数只接受列出的课时 ID 和该课显式门禁，不接收任意 shell。

| 课时 | 要验证的问题 | 运行方式 |
| --- | --- | --- |
| s02-fifo | 用户一次输入两行时，第二行会不会丢失或抢跑？ | `npm run lesson -- s02-fifo` |
| s02-resume | 恢复失败时，是否应该悄悄创建另一个 Thread？ | `npm run lesson -- s02-resume` |

离线实验使用临时目录、假 RPC 或本地协议进程，调用真实产品模块并执行 assert；不读取本阶段的 .env、不连接外部模型、不访问生产资料。子测试只继承系统路径与临时目录环境，不继承提供商凭据。测试结束清理自己创建的临时文件。

## s02-fifo · 终端提前输入也不能丢

输入队列保留 readline 先到的行；聊天循环按轮次消费，Codex 维护 Thread 上下文。

观察：提前输入的 first / second 按顺序取出；同一 Thread 产生两个 turn；旧轮 STALE 事件不会串入新答案。

边界：离线协议夹具：执行本阶段的真实入口，使用本地假 App Server；不调用模型，不证明模型回答质量。临时文件结束后删除。 本课是终端缓冲，不是 HTTP 服务消息队列。

## s02-resume · 恢复 Thread 而非重放聊天

产品只保存选择与切换规则，历史仍由 Codex Thread 承担。

观察：选中 saved-thread 后沿用该 ID 和只读权限；取消、无结果、失败时保留原会话。

边界：离线协议夹具：执行本阶段的真实入口，使用本地假 App Server；不调用模型，不证明模型回答质量。临时文件结束后删除。
