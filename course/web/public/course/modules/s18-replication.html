副本与故障接管：有人接手，丢多少说得清

先拍快照再慢慢发，按会话标记尾部丢失；旧主先当副本，追平后才能再当主。

每个分片一主一从，环形放置

上一章让云端 Agent 的每台机器都干活，但用户历史只在一块磁盘上，主节点坏了只能等。本章提前把历史复制到另一个节点，让它能接手；复制会慢一步，因此还必须说明哪些内容已经到达、哪些尾部可能丢失。

每个分片有一个副本，三个节点环形错开；每台既是一个分片的主，也是另一个分片的副本。CODEX_HOME仍按用户隔离，复制不改变 Hub 授权。

PG 保留任务事实、归属和复制位点，磁盘保存原生历史；任务写进 PG 不代表副本已有文件。etcd 提供租约和路由发布，副本只解决节点磁盘，不代表控制面也高可用。

只在轮次边界复制：先拍快照，再慢慢发

执行中复制 SQLite、会话记录和工具产物，可能得到一半新、一半旧的内容。轮次边界要求用户所有会话都没有执行中轮次，短暂暂停新派发、关闭空闲进程，拍下本地快照后立即放行，再异步发送；网络再慢，也不会把暂停拖到传输结束。

一轮结束后等 5 秒合并连续变化，每 60 秒检查空闲用户，内容没变则跳过。快照记下已完成到哪个任务，副本收齐 home、workspace 与附属内容并校验发布后，主节点才提交复制位点。

发送中新一轮结束，会记下变化，当前发送收尾后再调度。全量打包占磁盘、暂存和带宽，单次默认上限 1 GiB；超限会持续复制失败，不能当作可用副本。5 秒是合并等待，不是零丢失承诺。

复制位点之外，才是尚未复制的尾部

复制落后描述副本还缺多少已完成内容，帮助判断接管可能丢多少。轮数只计位点后的 completed，等待时间从最早未复制的完成轮次算起；没有尾部就为 0，不能把空闲很久误报成落后。

源码 · server/modules/replication/store.mjs · 第 6–11 行
export const LAG_MS = 5 * 60 * 1000;
export function lagOf(row, now = Date.now()) {
  const rounds = Number(row.lag_rounds || 0);
  const seconds = rounds ? Math.max(0, (now - new Date(row.pending_since).getTime()) / 1000) : 0;
  return { ...row, lag_rounds: rounds, lag_seconds: Math.floor(seconds), replica_lagging: Boolean(row.replication_error || row.transfer_started_at) || seconds > LAG_MS / 1000 };
}
源码解读

rounds 为零时 seconds 为零；错误、未完成传输或超过阈值触发落后。

未复制尾部超过 300 秒、复制错误或传输未完成时显示 replica_lagging。主节点仍可服务，/ready 保持 200 并附退化说明。replica_ready 表示完整基线已经建立，不表示副本与持续执行的主节点逐字节一致；副本离线或基线不全时不能接管。

限速给续约与请求留带宽，却可能扩大尾部窗口。传输连续 30 秒无字节进展才中止，持续有进展时没有整体 30 秒上限；用户暂停仍只到本地快照完成。参数与检查步骤见设计说明。

租约过期后接管，尾部丢失按会话粒度处理

接管必须先确认副本能用，不能为了恢复入口而接上不完整数据。主节点租约过期后，control 核对副本在线、全部用户有基线且无未完成传输，再在 PG 事务中更换主、推进 epoch，随后发布路由。

旧主回来：先当副本，追平了才能当主

旧主醒来可能仍以为自己有权写，但 epoch 已经增加，数据库直接以 SH001 拒绝旧任期。确认失去分片后，只停掉该分片用户进程，其他分片照常服务；无法确认归属或整个节点租约失效时仍需隔离。

接管成立，不等于所有故障都已解决

跨地域实验说明“能接手”和“适合长期服务”是两个问题。README 实测北京与美东往返 217 ms、隧道约 3 Mbit/s，主节点停止后 15 秒内副本接手；但 SQL 与 etcd 的反复往返仍会累积延迟。

无限速复制时，健康响应首字节曾等待 11.6 秒，超过 10 秒租约 TTL；20 MB 全量复制约需 1 分钟。放宽超时不能消除网络成本，节点与 PG、etcd、Redis 应在同地域、同一内网，往返不到 1 毫秒。实测与验收步骤见本章 README。

PG、Redis、etcd 和网关仍有单点，每个分片只有一个副本，没有自动再平衡。成员只认节点名，不验证磁盘是哪次复制的结果；换盘或恢复备份前需核对位点，或先以副本身份全量追平。离线实验不替代真实 PG、认证 etcd 和 Linux uid 验收。
