# 知识库批量导入 · 方案评审会纪要

时间：2026-10-15　　参会：产品、前端、后端、测试、客服各 1 人

## 结论

1. **Word（.docx）不进首期**，放到第二期；首期只做 Markdown 和 Notion 导出包。
2. **单次导入上限由 200 个调整为 500 个文件**（客服反馈大团队迁移普遍超过 200 篇）。
3. 去重方式确认：按文件内容计算 SHA-256 哈希，哈希相同视为重复，跳过并在报告中注明。
4. 目录结构：保留原层级；Notion 导出包里的页面 ID 后缀（如 `会议记录 3f2a…`）在导入时去掉。
5. 附件：单个附件超过 20 MB 时跳过，并在导入报告中列出；不中断整批导入。
6. 导入在后台任务中执行，用户可以关闭页面，完成后站内通知。

## 风险

- Notion 导出格式近一年改过两次，需要准备兼容层并保留样例回归测试。
- 大批量导入可能占满后台任务队列，需要按团队限流。
