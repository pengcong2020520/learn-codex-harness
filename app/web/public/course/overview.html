s00

先体验：把一件事交给 Codex

用官方 SDK 发起一轮任务；读文件、跑命令、改代码这个循环由 Codex 来转。

这一阶段新增模块

  • SDK 脚本接入与会话 · 官方 SDK 发起一轮

s01

先打通一次问答

自己写客户端，经 JSON-RPC 驱动 App Server；只有本轮成功结束，才算答完。

这一阶段新增模块

  • 单轮客户端接入与会话 · 发请求、核对终态

s02

让同一段对话继续下去

输入先排队再发送；每轮只发新输入，历史由 Codex 原生保存，退出后可以恢复。

这一阶段新增模块

  • 会话接入与会话 · 复用 Thread，整理快照
README ↗机制课长文章节阶段演示
s03

变成常驻服务：客户端走了，服务还在

服务端常驻运行、持有 Codex；终端客户端经 HTTP 提交和查看，关掉客户端不影响正在执行的一轮。

这一阶段新增模块

  • HTTP 接口接入与会话 · 常驻服务的入口
  • 生命周期与清理运行支撑 · 启停、运行目录回收
README ↗机制课长文章节阶段演示
s04

排队搬进服务端，状态推给客户端

输入先写进任务记录，按会话先进先出逐条发给 Codex；状态变化经 SSE 推给客户端，断线重连先补快照。

这一阶段新增模块

  • 任务与消息接入与会话 · 任务排队与调度
  • 事件推送接入与会话 · 状态变化推给客户端
  • 任务记录数据 · 任务状态，重启后可核对
README ↗机制课长文章节阶段演示
s05

一份 JSON 装配 Agent：角色与 Skills

Agent 定义决定角色、Skill、执行策略和工作区；启动时校验，内容一变旧版本就作废，会话与排队消息都要核对版本。

这一阶段新增模块

  • Agent 定义Agent 装配 · JSON 校验 + 版本哈希
  • 角色与 SkillsAgent 装配 · 做什么、怎么做
README ↗机制课长文章节阶段演示
s06

工具：读得到资料、存得下文章

工具来自配置，经 MCP 交给 Codex 调用；每次调用先核对白名单和参数，资料目录按用途授权，新建文件不覆盖。

这一阶段新增模块

  • 工具与资料边界Agent 装配 · 白名单 + 参数校验
  • MCP 工具入口Agent 装配 · Codex 回调本地工具
README ↗机制课长文章节阶段演示
s07

记忆：Codex 提炼，服务端管控

原生记忆默认关闭；总开关、读取和每个会话是否参与提炼由服务端决定，客户端只能查看、不能传路径。

这一阶段新增模块

  • 记忆运行支撑 · Codex 提炼，服务端管控

s08

让任务与产物有据可查

业务记录迁入 PostgreSQL，提交后经 Redis 唤醒执行；每个产物登记版本与来源。

这一阶段新增模块

  • PostgreSQL数据 · 业务状态的依据
  • Outbox + Redis数据 · 提交后再唤醒
  • 资源版本数据 · 产物可追溯来源

这一阶段新增模块

  • 可信门禁知识与工作流 · 服务端签发身份
  • Wiki / RAG知识与工作流 · 带原文依据的知识

Skill 教方法，Workflow 管边界和终点

一类任务一份配置；多步任务在关键处停下等人确认，模型可以提议提权，不能自己批准。

这一阶段新增模块

  • Workflow知识与工作流 · 步骤、确认与验收
  • 审批与提权知识与工作流 · 可以提议，不能自批

s11

模型网关：Codex 只连网关

网关统一协议、按任务把请求路由到各家模型；每轮记录 token 用量，超出预算就停止派发。

这一阶段新增模块

  • 生图与生视频模型网关 · 异步任务，结果存为产物
  • 用量与预算模型网关 · 超额停止派发
  • 模型路由模型网关 · 统一协议，转给上游

这一阶段新增模块

  • 就绪与容量部署 · 健康探测、限流与关闭
